# Whac-a-Mole Game 🎮

Un jeu Whac-a-Mole développé en Java avec interface graphique Swing.  
Projet personnel réalisé dans le cadre de mon apprentissage de la programmation.

## Description

Ce jeu reprend le principe classique du Whac-a-Mole : 
- Des taupes apparaissent aléatoirement sur une grille 3x3
- Le joueur doit cliquer dessus pour gagner des points
- Attention aux bombes ! Une seule touche et la partie s'arrête

## Fonctionnalités

- Interface graphique Swing (JFrame, JPanel, JButton)
- Apparition aléatoire des taupes et bombes avec des timers
- Gestion des événements de clic (ActionListener)
- Score affiché en temps réel
- Game Over avec arrêt du jeu
- Images personnalisées

## Technologies utilisées

- **Java** (JDK 8 ou supérieur)
- **Swing** pour l'interface graphique
- **AWT** pour les événements et timers
- **Git/GitHub** pour le versionnement
